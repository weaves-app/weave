## Additional risk checks linked to requirements

- FR-007 / S07–S11: deterministic race cases for old login vs logout, method switch, timeout, remount and background. Confirm no stale native activation or persisted session leak, not just absence of Home in the current render.
- FR-012 / S09/S12: test secure-storage read/write/clear failures; validate no credentials in snapshots or captured app/SDK logs using seeded secret strings. Native storage inspection checks platform backing; unit fakes alone cannot prove encryption.
- FR-015 / S18: SDK contract test confirms explicit non-transferable Google flow; verify unknown identity never calls signup and does not create an account on the shared instance. Avoid global registration-policy changes.
- FR-009/010 / S12–S14: fallback outside provider dependency failures; no `DevSettings.reload` dependency; disposal and revalidation run after each Reload.
- FR-001/004 / S06: real navigator behavior rather than only testing a route-selection utility; native callback handoff and Android activity recreation require device/emulator checks.
- SC-002: measure 2-second post-resolution navigation in controlled healthy-service native runs. S04 deadlines use injected time separately.

## CI execution

T008 adds test:native:android and test:native:ios scripts and invokes them in the required mobile-native platform jobs alongside compile checks. iOS tests require a runnable simulator destination. Native test failures fail the job; preserve test results. T038 verifies execution and records actual outcomes or an explicit unrun CI status. Gateway/controller fakes do not replace native contract suites or live acceptance.

## Evidence and completion

Create evidence.md during implementation with scenario IDs, exact commands, expected-red output, green output, refactor checks and native/manual outcomes. Record blocked prerequisites as blocked and unrun checks as unrun. Convergence must reconcile every scenario and FR with tests/manual evidence. Metro/native compilation does not prove OAuth, storage, accessibility or real-device correctness. Whole WEA-10 completion also requires the separately owned web and ticket signup/invitation scope; this mobile slice alone cannot complete the ticket.

T050/T051 refine S15/S16/S19: native bounds verify stationary shared controls and local transitions (including rapid toggles/reduced motion); LoginScreen tests verify partial versus complete code, automatic request payload, pending duplicate protection and retry after rejection. Native deterministic challenge checks verify automatic pending/error presentation; they do not establish successful real-provider authentication or delivered-code autofill.

T052 extends S15/S16/S19: LoginScreen regressions verify branding and verification Back remain outside the scrolling form for both code purposes, including pending disablement and return. Native Login/OTP captures verify identical centered logo bounds, top safe-area Back, keyboard/scroll reachability and enlarged text. Existing automatic-code/provider/access tests remain in force.

T053 extends S15/S16/S19: LoginScreen compares scroll alignment across both verification purposes; native iPad captures verify centered common frame and matching heading/logo origins in portrait, landscape and enlarged text. Phone regression flows cover automatic-code, error/resend/Back and narrow full-width layout.
