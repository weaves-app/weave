# WEA-6 quickstart

Follow root README for install/env/Docker start. Run `npm run verify`, `npm run db:deploy`, `npm run test:integration`; build the two images and run `node --test tests/containers/*.test.mjs`. Run `node scripts/check-sdd.mjs` for artifact validation. Review/trust project Codex hooks via `/hooks` before relying on them. First app-changing ticket branches from develop and follows the constitution/BDD/TDD workflow. PR links Linear WEA-6, spec and evidence.
