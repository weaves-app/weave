## Evidence shape

Each authored slice records scenario IDs, public seam, exact command, behavioral failure assertion/output, implementation result, refactor rerun and timestamp/commit context in feature evidence. Run targeted tests after each slice. CI/build success does not prove chronological TDD. Never paste real credentials or complete provider records into evidence.

Database evidence must use PostgreSQL with two independent client/process contenders, showing one provider reservation per second, cooldown preservation, failed-storage behavior and cleanup. HTTP tests exercise the composed Nest app, not only mocked controller methods. Include the compiled production module-loading path for jose.

Native checks include both public contract tests and real SDK integration builds. Device evidence records platform/OS/app commit, controlled account and installation aliases, permission/settings, connectivity, app state, provider send/check time, observed outcome and sanitized evidence reference. Missing device, beta access, APNs/FCM or signing remains an open acceptance item; mocks/simulator compilation cannot close it.

No delivery-time/exactly-once promise is added. Already queued/displayed OS messages are explicitly separate from future account-targeting after acknowledged eligibility change. Use only generic test titles/bodies. Final convergence must account for every S01–S11 row and SC-001–SC-008, with no invented pass.
